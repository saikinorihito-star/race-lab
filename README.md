# Race Lab — 競馬レース展開シミュレーター（試作 v0.1）

18頭の脚質・スピード・スタミナ・末脚を設定し、架空の競馬レースを再生する **iPhone向けPWA** です。

## できること
- 18頭の馬名・脚質・3能力を編集し、端末内に自動保存／JSONバックアップ・復元
- 距離（1200〜3000m）とペース（標準・ハイ・スロー）を選択
- 架空の速度モデルでレースを計算し、追走風と上空の2つの2Dビューで再生
- 1,000回の仮想レースを集計し、1着率・3着以内率・平均着順を表示
- 一時停止・早送り・再生位置変更
- 対応ブラウザーでは約12秒の録画ファイルを生成（MP4/WebMの形式はブラウザー次第）

## 重要な制約
- **実際の競馬データを用いた機械学習モデルではありません。** 能力値・確率・着順は架空の教育用モデルです。
- レースコースは抽象的な隊列表示で、京都・東京・中山等の実コース形状を再現していません。
- 追走ビューは2Dの疑似立体表示です。3D馬モデルは未実装です。
- 動画保存は `canvas.captureStream` と `MediaRecorder` が必要です。iPhone Safariの仕様・バージョン次第で使えない場合があります。その場合はiPhoneの画面収録をご利用ください。
- iPhoneで保存したファイルは「ファイル」アプリのダウンロードなどを確認してください。
- ブラウザーのローカル保存データは消失する場合があります。現在はクラウド保存・ログイン機能はありません。

## GitHub Pages で公開する手順
1. GitHubで **新規リポジトリ** `race-lab` を作成する（機密データは含めない）。
2. このZIPを展開し、`race-lab-pwa` 内の全ファイル（`index.html` ほか）をリポジトリの**最上位**にアップロードする。`tests/` は任意。
3. GitHubリポジトリの **Settings → Pages → Build and deployment → Deploy from a branch** を選び、`main` / `/(root)` を指定して保存する。
4. 表示されたGitHub Pages URLをiPhone Safariで開く。
5. Safariの共有メニューから **「ホーム画面に追加」** を選ぶ。

※ 公開設定は利用アカウントやリポジトリ種別に応じて利用可否を確認してください。GitHub Pagesに配置したアプリは原則ネット経由でアクセス可能です。利用データの保存は端末内のみです。

## Macでローカル起動
```bash
cd race-lab-pwa
python3 -m http.server 8000
```
その後、Macのブラウザーで `http://localhost:8000` を開きます。

## 自動テスト
```bash
node --test tests/engine.test.mjs
```

## 開発構成
- `engine.mjs` : 乱数シード付き仮想レースエンジン。ブラウザー非依存。
- `worker.mjs` : 別スレッドで1,000回の集計。
- `visual.mjs` : HTML canvas描画（2D）。
- `app.mjs` : iPhone画面・保存・動画出力・操作。
- `styles.css` / `index.html` : 画面設計。
- `sw.js` : PWAオフラインキャッシュ。
