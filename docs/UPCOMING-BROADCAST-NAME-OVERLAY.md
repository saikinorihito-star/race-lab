- 自動中継の先頭・3番手などの接近ショットで、見えている馬の馬名を短時間だけ表示できるようにする。

- 馬名はユーザーが入力した実データに紐づける。現行試験馬の識別は馬番であり、**実在馬名を勝手に付けない**。
