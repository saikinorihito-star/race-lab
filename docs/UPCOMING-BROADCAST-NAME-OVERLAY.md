# Design01 18頭レース：中継の馬名ラベル実装記録

更新日：2026-11-20
状態：**実装済み・GitHub Pages公開対象**。iPhone実機での見え方は別途検証。

## 要望と仕様

- 参考スクリーンショットのように、**低い斜め前の中継映像**で馬が大きく見える。
- 3D映像を覆う従来の大きな「中継」バーは**18頭モードのみ非表示**。FPS等の技術情報は3D映像の外に移す。
- 馬の頭上に**黒背景・白文字・角丸・下向き三角の馬名ラベル**を重ね、先頭→2番手→3番手の順に短い間隔で出す。
- 「3番手付近」の撮影では3〜5番手を対象にする。広角では最大2頭、それ以外は最大3頭。
- カメラ切替後の短時間に順番に表示し、しばらくして非表示に戻す。常時18頭分は出さない。
- 3Dメッシュの位置を画面座標へ投影し、馬の移動と追尾カメラに追従。画面外・UIに重なる場所・ラベル同士の衝突は非表示にする。
- 馬名は同じGitHub Pagesオリジンのメインアプリ保存データ（`race-lab-demo-v01`）を読み込む。存在しなければ「試験馬1」等にする。18頭ページ下部で個別編集でき、専用キーで保存する。
- **元Meshy版Design01のメッシュ、勝負服、走行アニメーション、2頭/4頭/8頭の承認済み動作は維持**する。
