- `design01-race.mjs` と `model-preview.mjs` の球体・ロフト由来の馬は**別の造形**。この承認済みDesign01の代替にしてはならない。

- 2026-11-19、**元の頂点位置・法線・UV座標・面構成・マテリアル・画像をそのまま保持**し、以前のギャロップV2の36ボーン・23アニメーションチャンネルを元の高精細メッシュへウェイト転写した。
- 出力: `RaceLab_OfficialDesign01_OriginalLook_GallopV2.glb`（36,652,756 byte）
- SHA-256: `2939c672d6a9f94ee071edbad84994406db2d37876931a715c17aac0b6aeb3b9`
- GLB内部の元モデルからの**頂点配列・法線・UV・画像・マテリアル参照の同一性をプログラムで確認**済み。
- 骨格を動かした0.14秒と0.28秒の姿勢で、3Dレンダリングの表示検査を実施。元の模様と顔が維持されている。ユーザーのiPhoneでの動き・FPSは未検証。
- 出力ファイルはChatGPT会話の生成添付。**現在GitHub本体へ大容量バイナリがアップロードされたわけではない。** 1頭ページで初回のみファイル選択、端末のIndexedDBに保存する。
- `tokyo-turf-a-elevation-rebuild.html?model=design01` の専用1頭表示だけ、ソース元と同じ **484,459頂点 / 2,733,876三角インデックス数** とV2アニメーションクリップ名を検証し、他モデルを拒否。古いGLBのローカルキャッシュキーから完全分離。

- **18頭の仮モデル、芝Aコース、発馬機、レースAIは現状維持。** 正式モデル1頭をユーザーが外観と脚運びで確認してから18頭展開。

## 今後の実装ガードレール
1. デザインを作り直さず、**元Meshy版の造形とテクスチャを維持**して、ポーズ・接地・脚運びを修正する。
2. 1頭のコース走行で向き、上下動、蹄の接地と宙に浮く時間、騎手の姿勢を確認。
3. iPhone SafariでのFPSとメモリ使用量を検証。必要な場合も形状・模様の見た目を変えない最適化だけ実施。
4. ユーザー承認前に18頭の正式モデルに展開しない。
